# 파이프라인 (R3)

> 참조: [R2-purpose.md](R2-purpose.md), [R1-B-story-work.md](R1-B-story-work.md)

## 단계

| 단계 | 입력 | 출력 | 비고 |
|---|---|---|---|
| S1 수집 | 화면 이름 | 레퍼런스 목록 (≥5건) | R1-B-story-work.md 1번 |
| S2 분석 | 레퍼런스 목록 | 반영할 부분 목록 (근거 번호 포함) | 2번. ⏸ 사람 판단 (무엇을 가져올지) |
| S3 설계 | 반영할 부분 목록, PRD 16장 | 화면 설계서 | 3번 |
| S4 사전점검 | 화면 설계서, design.md | 위반 예상 목록 (0건이면 통과) | 신규 단계 |
| S5 시안 | 화면 설계서, design.md | Figma 키 스크린 (390×844) | 4번 |

## 되돌아가는 곳

| 실패 지점 | 돌아가는 곳 | 이유 |
|---|---|---|
| S2 반려 | S1 수집 | 레퍼런스가 부족하거나 엉뚱함 |
| S4 위반 예상 | S3 설계 | 설계서에 위반 요소가 있음 (임시 결정, 아래 참조) |
| S5 위반 발견 | S5 시안만 다시 | 설계서는 유지 |

## 재시도 한도

- 단계당 최대 2회. 초과하면 멈추고 나에게 보고한다.

## 미확정 사항

- S4 사전점검 실패 시 복귀 지점: 답을 받지 못해 S3으로 임시 지정
